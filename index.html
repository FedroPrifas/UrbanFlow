INTRODUÇÃO

O UrbanFlow é um sistema de apoio à decisão voltado para deslocamentos urbanos, desenvolvido com o objetivo de auxiliar os usuários na escolha de rotas mais adequadas para seus trajetos. O sistema analisa diferentes informações relacionadas ao percurso, como tempo, distância e condições externas, utilizando dados obtidos por meio de serviços de mapas e informações climáticas.

Um dos principais recursos do UrbanFlow é o Índice de Mobilidade, que reúne e organiza essas informações para apresentar uma visão geral das condições de cada trajeto. A partir desse índice, o sistema consegue comparar diferentes alternativas e classificá-las de acordo com os critérios definidos no projeto, facilitando a compreensão das opções disponíveis para o usuário.

Dessa forma, o UrbanFlow não busca apenas indicar uma rota, mas oferecer informações que auxiliem o usuário a tomar uma decisão mais consciente sobre seu deslocamento. Ao combinar os dados das rotas com o Índice de Mobilidade, o sistema permite analisar as alternativas de maneira mais ampla, considerando tanto a eficiência do percurso quanto as condições encontradas ao longo do trajeto.

NECESSIDADE DO PROJETO

A necessidade do UrbanFlow surgiu a partir da dificuldade encontrada pelos usuários no momento de escolher uma rota para seus deslocamentos urbanos. Atualmente, muitas ferramentas priorizam principalmente fatores como menor distância ou menor tempo de viagem, sem apresentar uma análise mais ampla das condições que podem influenciar o percurso. Com isso, o usuário pode ter dificuldade para comparar as alternativas disponíveis e escolher aquela que melhor atende às suas necessidades.

Diante disso, o UrbanFlow busca oferecer uma solução que reúna diferentes informações sobre o trajeto e utilize o Índice de Mobilidade para facilitar a comparação entre as rotas. Dessa forma, o sistema pretende fornecer informações mais organizadas e claras, permitindo que o usuário tenha uma visão melhor das condições de cada alternativa antes de realizar seu deslocamento.

OBJETIVO GERAL

Desenvolver um sistema de apoio à decisão para deslocamentos urbanos, capaz de analisar diferentes fatores que influenciam as condições do trajeto e auxiliar o usuário na escolha de uma rota mais adequada, utilizando o Índice de Mobilidade para facilitar a análise e comparação entre as alternativas disponíveis.
